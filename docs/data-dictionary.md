# Data Dictionary

## people
Sanitized person records. Safe for normal dashboard use.

## person_sensitive
Admin-only PII collection. Contains passport/DOB/image/phone fields only when present.

## participation
Conference role/session/presentation/status/support fields.

## hotel_bookings
Hotel logistics fields. Restricted to logistics/admin.

## flight_segments
Arrival/departure flight segments. Restricted to logistics/admin.

## pickup_tasks
Pickup tasks. Restricted to logistics/admin.

## agenda_items
Agenda/session items.

## data_quality_issues
Validator output. Sensitive evidence is masked.

## raw_sheet_snapshots
Raw row-level source snapshots for audit. Admin only.

## dashboard_metrics/current
Aggregated dashboard counters.
